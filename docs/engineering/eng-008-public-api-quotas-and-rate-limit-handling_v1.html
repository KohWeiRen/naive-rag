Request budget

The tenant API permits 600 requests per minute per tenant in each region. A short burst of 120 requests in a 10-second window is allowed. Large report exports have a separate job quota of two concurrent exports per tenant.

Client behavior

When you receive 429, read Retry-After and use jitter before retrying. Batch requests where the endpoint accepts a batch. Avoid restarting a full pagination sequence after a single throttled request.

Operations

Contact Support with the request ID and UTC timestamp when a repeated throttle happens below the documented quota. Escalate requests for a permanent quota change to Product and Platform Engineering.
