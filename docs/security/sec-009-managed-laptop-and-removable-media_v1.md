# Managed laptop and removable media

Company: Ternwell Systems
Document ID: SEC-009
Type: Policy
Owner: Security
Issued: 2026-07-30
Status: Current

Employees use managed devices for company work. Device encryption, screen lock, endpoint monitoring, and automatic security updates are enabled through the device profile. Reboot within the maintenance window when prompted by IT.

## Removable storage

Use only company-issued encrypted media when a documented task requires it. The help desk records who received the device and when it must be returned. Store support exports in approved company storage.

## Loss or theft

Report a lost device promptly. Include the last known location and whether it was signed in. IT revokes sessions and coordinates recovery or remote wipe with Security.
