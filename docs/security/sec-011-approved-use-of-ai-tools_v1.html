Data handling

Employees may use approved AI tools for tasks within the data classifications covered by the vendor agreement. Never submit Restricted material or production credentials. Use synthetic examples for prompts that do not require customer data.

Output review

Treat generated code, summaries, and translations as drafts. The owner checks relevant facts and tests changes before publishing or deploying. Record any customer-facing AI feature in the product risk register.

New tools

Request review before adding a new integration to a corporate account. Provide the proposed use, input data, retention settings, and whether the tool can write to another system. The assessment follows SEC-004.
