# Quarterly access review

Company: Ternwell Systems
Document ID: SEC-012
Type: Checklist
Owner: Security
Issued: 2026-10-15
Status: Current

Review service owners, staff groups, vendor accounts, and dormant accounts. Compare current grants with employee roles and active work requests. Remove expired vendor accounts and replace accounts shared by a team with named or workload identities. Review exceptions with the Security lead and capture the reason and expiry for each. The reviewer and a second approver sign the final record.
