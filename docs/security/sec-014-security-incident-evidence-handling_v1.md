# Security incident evidence handling

Company: Ternwell Systems
Document ID: SEC-014
Type: Procedure
Owner: Security
Issued: 2026-09-12
Status: Current

Preserve logs in their original export format and record the source service, collector, collection time, and incident ID. Add a hash for large binary exports. Store an immutable copy in the restricted incident workspace and perform analysis on a working copy.

## Chain of custody

Record transfers and access grants in the evidence log. Note why the recipient needs the record and when access should end. Use UTC timestamps throughout the case. Security manages retention and consults Legal if evidence may be subject to a preservation hold.
