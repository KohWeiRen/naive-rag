# Reporting a suspected security incident

Company: Ternwell Systems
Document ID: SEC-007
Type: Runbook
Owner: Security
Issued: 2026-09-22
Status: Current

## First actions

Open a restricted incident ticket and notify the Security duty contact. Include the time, affected account or service, observed action, and the first safe containment step. Keep original messages, audit event IDs, and system timestamps.

## Triage

Security assigns a severity and names the incident lead. A security incident may also use the service incident workflow in OPS-001. Isolate an affected device or revoke a credential if the incident lead approves. Record containment and recovery actions as they occur.

## Communications

Security and Legal determine whether notification is needed. The incident lead shares verified facts with affected service owners through the restricted incident channel. Store evidence in the incident workspace and avoid copying it to general chat.
