What changed

The export history panel shows which jobs are queued, running, ready, or expired. Operators can see the filter summary without opening the downloaded file. New customer admins receive a guided gateway enrollment panel.

Improvements

Webhook delivery history now shows attempt count and response class. Support cases can include the delivery ID without screenshots. The release also improves keyboard navigation in the site picker.

Availability

Singapore and EU tenants receive the release in separate canary waves. The gateway sample status trial remains limited to the Bracken Dairy pilot.
