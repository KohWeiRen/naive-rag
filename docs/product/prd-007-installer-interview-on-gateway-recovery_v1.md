# Installer interview on gateway recovery

Company: Ternwell Systems
Document ID: PRD-007
Type: Research notes
Owner: Product
Issued: 2026-10-02
Status: Current

Two Rotterdam installers walked through enrollment recovery with a demo gateway. Both checked power before asking for a fresh enrollment code. One assumed the code worked for any tenant, which delayed troubleshooting when the site region did not match.

## Findings

Show the tenant name, region, and expiry beside the code. Add a link to the transfer workflow for gateways that already have an assignment. Reuse the recovery language in CS-005. Treat these interviews as directional feedback and verify the change in a staffed field pilot.
