# Starting a Wayline customer pilot

Company: Ternwell Systems
Document ID: CS-002
Type: Playbook
Owner: Customer Enablement
Issued: 2026-09-10
Status: Current

## Kickoff

Confirm the tenant owner, service region, sites, pilot dates, and acceptance criteria. Build a demo account before enrolling any real gateway. Customer data remains in the contracted service region.

## Pilot

Start with one site and one threshold profile. Add the site label, assign gateways, and validate a live reading. Review the exception log during the first week. If alerts go to a webhook, verify signing, a retry, and deduplication in the customer's sandbox.

## Exit criteria

The customer confirms readings are visible, alert targets work, and operators can view the last accepted sample. Customer Enablement records open blockers and an owner for each. If an issue remains, agree on an extension before expanding the pilot.
