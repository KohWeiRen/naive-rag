Current

Expired code

Generate a fresh enrollment code in Fleet Console. A code expires after 24 hours and can be used once. Check that you are signed into the tenant that owns the destination site.

Already assigned

Ask your tenant administrator to use the transfer procedure for the gateway. If the current assignment appears in another tenant, contact Support with the gateway serial and destination region.

Connection error

Check power and network connectivity. Record the error text and UTC timestamp. A failed request can still appear in the device history if it reached the regional endpoint. Support checks this before recommending a reset.
