# Replacing a failed cold-room gateway

Company: Ternwell Systems
Document ID: OPS-008
Type: Runbook
Owner: Fleet Operations
Issued: 2026-09-14
Status: Current

Confirm the site has a spare gateway with approved firmware. Record the failing unit's serial, last signal time, and site label. Ask the site contact to check power before authorizing a physical replacement.

## Swap

Enroll the spare in the same region and assign it to the site. Verify one live reading from each attached sensor. Label the old gateway with the case ID and place it in the return kit. Avoid reassignment to another tenant until Fleet Engineering confirms it has been reset.
