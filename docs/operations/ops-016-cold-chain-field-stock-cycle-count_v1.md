# Cold-chain field stock cycle count

Company: Ternwell Systems
Document ID: OPS-016
Type: Procedure
Owner: Fleet Operations
Issued: 2026-10-17
Status: Current

Each site counts spare gateways and probe kits on the third working day of the month. Match serial numbers to the inventory register. Mark quarantined units separately and photograph damaged packaging before raising a discrepancy.

## Escalation

Report a variance greater than two gateways to the regional stock owner the same day. If a unit is tied to a live tenant, Fleet Engineering must confirm the assignment before inventory is corrected. Finance reconciles replacement stock and courier charges after the operations owner approves the variance.
