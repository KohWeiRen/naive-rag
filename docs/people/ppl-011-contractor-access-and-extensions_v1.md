# Contractor access and extensions

Company: Ternwell Systems
Document ID: PPL-011
Type: Procedure
Owner: People Operations
Issued: 2026-06-15
Status: Current

## Sponsorship

Each contractor has a named employee sponsor and a recorded assignment end date. The sponsor requests the specific applications and project groups required. IT issues a managed account with MFA and sets an expiry date in the identity system.

## Extensions

Submit extensions at least five working days before expiry. Include the purchase order or contract extension and remove permissions that are unnecessary for the next phase. Accounts that expire must be reviewed and reapproved before reactivation.

## Production access

Any production access follows SEC-002. The sponsor records the task and review window. Pairing with a staff engineer remains the preferred way to complete an elevated task where practical.
