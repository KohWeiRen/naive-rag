# Offboarding and role changes

Company: Ternwell Systems
Document ID: PPL-009
Type: Policy
Owner: People Operations
Issued: 2026-10-01
Status: Current

## Departure workflow

The manager opens an exit request as soon as the departure date is confirmed. IT schedules account removal for the approved time and records completion. The manager transfers ownership of calendars, project spaces, service accounts, and open customer cases before the account is disabled. Employee and contractor equipment must be returned or tracked with a courier reference.

## Internal transfers

The receiving manager requests only the permissions needed for the new role. Security reviews elevated permissions and conflicting access before the effective date. Old group membership should be removed at the time of transfer unless a time-limited exception has been approved.

## Verification

Confirm removal from the identity provider, code repositories, production roles, and customer support tools. Save evidence in the exit request. Escalate any account still active after the agreed removal time to Security.
