Schedule a monthly check-in and ask the employee to suggest one topic before the meeting. Open with progress on the previous action, discuss workload, and write one observable goal for the next month. Goals should name a result or behavior. The employee and manager should both be able to see the notes.

Examples

A useful goal for a support specialist is to produce and test an escalation checklist for device enrollment. For an engineer, an example is to add coverage for webhook retries and review the failure logs with the on-call lead.

Escalation

Use the private People Portal workflow for accommodations, performance concerns, or matters involving another employee. Keep sensitive personal details out of team dashboards.
